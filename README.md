# 小学校5年生向け 分数計算30分ドリル

小学5年生の算数単元「分数のたし算とひき算（通分・約分・帯分数）」に特化した学習Webアプリケーションです。  
Chromebookでの快適なキーボード操作、実質的な学習時間（30分）の正確な計測、端末内への回答ログ蓄積、そして**Googleスプレッドシートへの1分おき自動保存 ＆ スマート保存ボタン**に対応しています。

---

## 🌟 主な特徴と仕様

### 1. 小学5年生に特化した分数計算エンジン
- **出題モード**:
  - **ミックス固定**（帯分数・真分数、通分あり、繰り上がり・繰り下がり、約分ありをバランスよく自動生成）。
- **帯分数・仮分数の両対応**:
  - **帯分数（例: $1\frac{2}{3}$）でも、仮分数（例: $\frac{5}{3}$）でも、約分されていればどちらでも正解になります。**
  - 約分していないもの（例: $1\frac{4}{6}$ や $\frac{10}{6}$）は「まだ約分できるよ！」とヒントが出ます。

### 2. シンプルで安全なログインフロー（パスワードなし）
- **毎回ログイン**:
  - アプリ起動時に「クラス」と「出席番号」を選択。
- **登録済みの場合**:
  - 「**〇〇さんですね！合っていますか？**」とお名前が大きく表示され、「はい、学習スタート！」を押すだけで開始できます。
- **初回の場合**:
  - ニックネーム（ドリルで呼ばれる名前）を入力して「登録してスタート！」を押すと、スプレッドシートの「児童名簿」へ自動登録されます。

### 3. スマート保存ボタン（スプレッドシート連携）
- **保存が必要なときだけ押せる**:
  - 未送信の回答がある時: `☁️ 今すぐ保存 (N問)`（青色ボタン・クリック可能）
  - 保存処理中: `⏳ 保存中...`（ボタン自体が変化・連打防止）
  - 保存完了時: `✅ 保存完了`（緑色ボタン・クリック不可）
- **1分おき自動保存**:
  - ボタンを押さなくても、1分ごとにバックグラウンドで未送信データを自動送信します。

### 4. 放置防止 ＆ 実質30分学習タイマー
- 60秒間無操作で「お休み中かな？」と自動一時停止。
- 別タブ閲覧やChromebookの蓋を閉じた瞬間も自動停止（Page Visibility API）。
- 実際に集中して解いた時間だけで30分をカウントします。
